# 技能目录（skills）

每个子目录是一个**技能**：里面放 `SKILL.md`，正文是给模型看的指令。写法：

```markdown
---
name: 技能名（可省，默认用目录名）
description: 一句话说明（可省）
---
正文：具体规矩。会被原样拼进系统提示。
```

也可以直接放 `技能名.md`（懒人写法）。**技能只是文本**：不会被本应用执行，
和方案文档走同一条路进提示词。

在「设置 → 内置 agent → 技能」里可以指定技能目录与启用的技能（留空 = 用本目录里的全部）。
只对**内置 agent（直连模型 API）**生效；opencode / claude / codeagent 有各自的技能机制。

仓库自带的技能：

| 技能 | 作用 |
| --- | --- |
| `shell-strict` | 写 bash 脚本的硬规矩（引号、严格模式、危险命令保护、可重复执行） |
